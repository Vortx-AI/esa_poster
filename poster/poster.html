01

CONTENT ID

The observation record is (cell, band, tslot, value, uncertainty, sources, derivation, signer, signed_at). Deterministic emem-CBOR is hashed with BLAKE3; the served bytes must re-hash to the id.

real Keylong NDVI · verify_ndvi.pyfact oj5cecci… 1,115 bytes re-hash MATCH B08 DN 3502 B04 DN 1900 offset −1000 signed 0.4708994708994709 rebuilt 0.4708994708994709 bit-identical same cid under another cell → HTTP 409
checkchanged bytes → changed id; wrong place → HTTP 409. The same digest is also emitted as CIDv1 for generic content-address tooling.boundarythe id names one signed record because signer and signed_at are inside it; it is not a universal “truth id”.
02

HANDOFF

Agent B does not need Agent A’s transcript to recover the evidence. It needs the token. For many cited observations, emem:bundle: carries up to 256 fact references under one compact handle.

measured paraphrase trap · one real Lahaul factsigned NDVI 0.4871541501976284 decision rule WATER if NDVI < 0.488 token handoff Gemma WATER · Qwen WATER correct prose “≈ 0.49” Gemma SKIP · Qwen SKIP agree + wrong
long runbundle: ≤256 facts · 38 characters · ~23 LLM tokens. In the measured 599-turn run, bundle answers were 100% citable vs BM25 0%.boundaryone fact token is ~51 LLM tokens; bundling—not a single token—is the context-saving mechanism.
03

FIELD / CUBE / EMBEDDING

emem:raster: names a spatial field; emem:cube: binds fields through time. The live Tessera encoder’s 128-D output is stored as a typed model_output fact: the embedding is a value inside an addressable record, not the memory itself.

real Keylong B08 cube · Fig. 215 May → 10 Jun (+26 d) 15 Jun → 30 Jun (+15 d) 15 Jul → 03 Aug (+19 d) 15 Aug → 13 Sep (+29 d) 15 Sep → 25 Sep (+10 d) 5 artifacts re-hashed ✓
flowSentinel-2 → field / Tessera 128-D → signed record → token → any connected agent runtime.boundaryscene selection uses scene-level cloud cover; re-minting can produce a new derivation id for identical pixels.
04

CLAIM CHECK

guard/verdict resolves citations in a draft and compares the written number with the signed value at the writer’s precision. A mismatch returns a typed reason and fix.

Pre-registered result; Fisher one-sided. Two open models on one host; no independent replication. The known phenomenon is lossy multi-agent communication. emem’s contribution is a handoff object whose cited evidence can be recovered and checked instead of paraphrased.

What holds: byte identity, spatial binding, signer/receipt integrity, replayable cited state.

What does not: objective truth, sensor accuracy, model correctness or a guarantee that the prose conclusion follows from the cited band.

The poster uses real tokens, real Sentinel-2 grids and independently re-run checks. Detailed prior art, audit defects, withdrawn claims and all reproduction scripts stay in the repository rather than competing for wall space.
