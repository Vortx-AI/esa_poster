emem: A research on Content-Addressed, Verifiable Earth-Memory Protocol for AI Agents over Foundation-Model Embeddings

Jaya Kumari · Avijeet Singh — Vortx AI · doi:10.5281/zenodo.20706893 · claims pinned to emem 64cfae5; every live value below obtained from emem.dev on 29 Sep 2026 — integrity checks (A1–A3, A8) re-run with independent code
Referential drift starts when evidence becomes prose.
A real Lahaul NDVI value of 0.4871541501976284 became “≈ 0.49”. Two models agreed more — and both crossed the irrigation threshold the wrong way.

emem changes the handoff unit. Carry the address of the signed observation record, not a sentence about it. A later agent resolves the record, re-hashes the bytes and verifies the attestation before reasoning from it.

OBSERVE → ADDRESS → HAND OFF → RESOLVE → VERIFY → CONTINUEThe agent is temporary. The cited world-state is not. Integrity is checkable; measurement truth is not implied.

Three EO objects

bundle, entity and cell intentionally have different strengths. The protocol does not pretend every token means “same bytes”.

01

ADDRESS · the observation record names itself

A record is (cell, band, tslot, value, uncertainty, sources, derivation, signer, signed_at). emem serialises it deterministically; BLAKE3 of those exact bytes becomes its content id.

real Keylong NDVI · verify_ndvi.pyfact oj5cecci… 1,115 bytes re-hash MATCH B08 DN 3502 B04 DN 1900 offset −1000 signed 0.4708994708994709 rebuilt 0.4708994708994709 bit-identical same cid under another cell → HTTP 409
invariantchanged bytes → changed id; wrong place → fail closed.boundarythe CID names one signed record because signer and signed_at are inside the record; it is not a universal “truth id”.
02

HAND OFF · carry the address, not the paraphrase

A trust boundary does not need the previous model’s context. It needs the token. The receiving agent can resolve → re-hash → verify → reason from the same cited record.

measured paraphrase trap · one real Lahaul factsigned NDVI 0.4871541501976284 decision rule WATER if NDVI < 0.488 token handoff Gemma WATER · Qwen WATER correct prose “≈ 0.49” Gemma SKIP · Qwen SKIP agree + wrong
driftthe reference survives even when context is compacted, replaced or moved to another model.boundarya valid token does not make a model’s conclusion correct; it makes the evidence it cited recoverable and checkable.
03

FIELD · give the model pixels, not prose about pixels

emem:raster: names a spatial field through a signed derivation; emem:cube: binds independently resolvable fields through time. The derivation pins AOI, band, scene, recipe, date and artifact hash.

real Keylong B08 cube · Fig. 215 May → 10 Jun (+26 d) 15 Jun → 30 Jun (+15 d) 15 Jul → 03 Aug (+19 d) 15 Aug → 13 Sep (+29 d) 15 Sep → 25 Sep (+10 d) 5 artifacts re-hashed ✓
usesatellite state enters reasoning as an addressable field, and the temporal substitution is explicit rather than hidden.boundaryscene selection uses scene-level cloud cover; re-minting can produce a new derivation id for identical pixels.
04

VERIFY · check the sentence before it leaves the agent

guard/verdict resolves citations in a draft and compares the written number with the signed value at the writer’s precision. A mismatch becomes a typed refusal, not a confidence score.

real Bengaluru temperature fact = 28.0 °C“… was 35 °C (token)” deny PROV_VALUE “… was 28.0 °C (token)” allow same cid under another cell deny PROV_BYTES uncited measurable claim, gating deny CLAIM_UNGROUNDED
loopOBSERVE → ADDRESS → HAND OFF → RESOLVE → VERIFY → CONTINUE.boundarythe hosted guard is advisory; it does not yet check whether the cited band semantically matches the sentence.
SIGN ABSENCE“looked, nothing there” stays distinct from “could not look”.
KEEP DISAGREEMENTconflicting attestations remain separate; they are not silently averaged.
RE-DERIVEdeterministic derivatives are recomputed and their numerical gap is reported.
AUDIT HISTORYattestations enter an append-only Merkle log with offline-checkable proofs.

Pre-registered result; Fisher one-sided. Two open models on one host; no independent replication. The known phenomenon is lossy multi-agent communication. emem’s contribution is a handoff object whose cited evidence can be recovered and checked instead of paraphrased.

What holds: byte identity, spatial binding, signer/receipt integrity, replayable cited state.

What does not: objective truth, sensor accuracy, model correctness or a guarantee that the prose conclusion follows from the cited band.

The poster uses real tokens, real Sentinel-2 grids and independently re-run checks. Detailed prior art, audit defects, withdrawn claims and all reproduction scripts stay in the repository rather than competing for wall space.
