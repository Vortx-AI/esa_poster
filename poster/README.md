Issue #48 and its follow-up define this edition. It keeps the original reading flow and puts the complete mechanism before the experiment: Earth observation → lookup → record → reference → receiving agent → checks → continued reasoning.

The header, captions, conclusion and ecosystem copy now describe that system directly. Research questions, threat-model prose, detailed token grammars and the execution diagram remain in the methods. The Berlin image and native-grid table have more room. Three printed QR tasks lead to **Try it**, **Inspect** and **Reproduce**.

The numeric findings and their original measurement files are unchanged. The pooled Claude result remains 254/276 for prose and 0/300 with checking instructions; the separately labelled Qwen result is 22/23 and 2/25. The recorded two-process handoff is explicitly a program experiment. ChatGPT is labelled as a publisher listing, not promoted to a tested runtime.

Build source: `src/poster.v13.html` and `src/poster.v13.css`. Current copy specification: [14_UNIFIED_POSTER_BRIEF.md](../research/v13/14_UNIFIED_POSTER_BRIEF.md). The claim additions explain the new qualitative copy while preserving the measured rows. Full build instructions are in [AGENTS.md](../AGENTS.md).

The QR pages at [vortx-ai.github.io/esa_poster](https://vortx-ai.github.io/esa_poster/) are generated by `build_site.py` and publish from `main` → `/docs`.

Validation: all 17 poster gates pass; the A0 was visually reviewed, and a fresh deterministic R1 run reproduced the committed verdicts. Phone layout, the offline demo, static fallback and all six web QR payloads pass. The full browser suite exits nonzero because this build environment cannot fetch emem.dev or the external source imagery; live resolution and source re-read are therefore **unverified in this release run**. The raw [site results](../docs/assets/screens/results.json) retain those failures. See the [release review](../research/v13/15_RELEASE_REVIEW.md) for issue coverage and scope.
