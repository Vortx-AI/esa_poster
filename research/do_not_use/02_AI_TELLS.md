# Visual and language tells to avoid

This file exists because the poster must look like a serious systems / EO research contribution, not an AI-generated startup board.

## Visual tells

Avoid:
- cinematic Earth horizon occupying half the poster;
- generic satellite beams;
- glowing cubes with unexplained layers;
- robot characters;
- rows of product capability cards;
- gradient-heavy blue/purple neon;
- five-step icons;
- "AI brain" imagery;
- logo clouds;
- generic map screenshots without scale/source/date;
- decorative code snippets that are not executable;
- fake scientific equations.

Use instead:
- one actual protocol object;
- one actual token;
- one actual observation body;
- one real hash/verification path;
- one actual field/cube derivation;
- source scene id / date / band;
- small diagrams with named inputs and outputs;
- enough whitespace for people to inspect the mechanism.

## Language tells

Avoid:
- revolutionary
- game-changing
- groundbreaking
- seamless
- unlock
- empower
- intelligent insights
- next-generation
- end-to-end intelligence
- AI-powered
- trustworthy by design
- one source of truth
- no hallucinations
- guaranteed accuracy
- democratise intelligence
- future of Earth observation

Prefer:
- resolves to
- binds
- hashes
- signs
- replays
- re-derives
- fails on mismatch
- survives a reset
- returns byte-identical content
- pins the source / recipe / time
- independently verifies
- does not prove

## Poster reading test

A scientist should be able to point at each major visual and ask:

> "What exactly am I looking at?"

There should be a literal answer:
- an observation;
- canonical CBOR;
- a BLAKE3 digest;
- an emem fact token;
- an Ed25519 receipt;
- a raster derivation;
- a handoff boundary;
- a context reset.

If the answer is "a concept", redraw it.

## The strongest aesthetic

Think:
- systems paper figure;
- remote-sensing methods diagram;
- protocol RFC;
- lab notebook;
- reproducible experiment.

Not:
- product launch;
- venture deck;
- sci-fi movie;
- agent cartoon;
- SaaS landing page.
